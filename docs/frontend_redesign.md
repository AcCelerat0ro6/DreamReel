# DreamReel 前端重构

2026-11-06。基于现有 React 18 + Vite 项目实现，继续使用现有 Go API，未增加前端运行依赖。

## 设计与结构

采用浅灰背景、白色卡片、淡紫品牌色、SVG 图标和本地默认图片。桌面为导航、放映区与社区观察栏；小屏切换底部导航，顶部保留搜索、发布、消息和登录／个人主页入口。

- `src/components/AppShell.jsx`：导航、品牌与搜索。
- `src/components/VideoStage.jsx`：播放器、作者、互动与 AIGC 信息。
- `src/components/DiscoveryPanel.jsx`：真实模型榜单摘要、下一部作品与创作入口。
- `src/components/UploadPage.jsx`：创作工作室与按用户隔离的文字草稿。
- `src/discovery.js`、`src/playback.js`：筛选、分享定位、播放手势与 QoS 计时。
- `src/pages.css`：账户、资料、作品、消息与评论的浅色布局。

| 主页 | 个人资料、昵称／简介／头像编辑、作品弹窗、关注／粉丝列表和分页 |
| 公开主页 | 公开资料与作品、资料缓存、原生视频控制 |
| 消息 | 未读提示、刷新、单条／全部已读、加载更多 |

| AIGC 字段 | 模型、版本、风格、生成参数／提示词、原作品 ID，以及前后端一致的字符数校验 |

## 新增和修复

1. 点击视频画面暂停／继续，支持空格；拖动超过阈值不会误触暂停，输入评论或拖动进度时不会触发视频流快捷键。
2. 真实进度、时间、声音开关、全屏、缓冲及失败重试，替换原来的固定进度条。
3. 沉浸播放／网格浏览切换；按标题、作者、模型、风格和提示词搜索，并按模型筛选。范围明确为当前已加载视频，可继续加载更多。
4. 可复制作品分享链接，固定公开 `/timeline?video=ID`；目标未在第一页时通过公开详情补取，失效作品给出提示。
5. AIGC 信息展开与提示词／参数复制，显示复制结果。
6. 上传文字草稿按账号自动保存、恢复与清空；成功发布后清除。文件不存入草稿，重新进入需要重新选择。
7. 模型与风格快捷选择、模型版本自填、实时预览、分步创作表单。
8. 真实模型榜单侧栏与本页统计概览；统计概览明确标注本页范围。
9. 修复手机消息入口、个人页退出入口、登录注册页独立滚动、评论 Esc 关闭；图标与默认封面不再依赖外部字体或图片服务。

## 验证

运行 `npm run build` 和 `npm test`。测试覆盖原推荐续刷、上传管理、AIGC 校验，以及新增播放／QoS／手势、搜索索引和分享补取。

使用本机实际运行的 API 和浏览器验证：视频画面点击暂停与恢复、原生作品弹窗点击暂停、声音、全屏、评论抽屉、搜索网格、模型榜单、个人／公开主页、消息、文字草稿保存和刷新恢复、作品链接复制及定位。检查桌面和 390px 小屏布局。

未通过浏览器发布测试作品或新增账号；真实文件上传和发布的并发、重试、取消及幂等行为由保留的实现和自动测试覆盖。

备份和恢复方法见 `backups/README.md`。前端启动和代理配置不变，开发地址 `http://127.0.0.1:5173`。

## 账户与创作交互调整

- 右上角头像在其他页面进入个人主页；在个人主页展开编辑资料、退出登录菜单，支持键盘操作和点击外部收起。
- 创作工作室统一使用 /create，兼容原 /upload 路径；横幅只在创作页显示，点击开始创作滚动到表单。
- 登录页使用轻量 Canvas 粒子、浮动影像和表单滑入效果，创作页增加同类动效；适配减少动态效果设置，后台页面暂停粒子绘制。
- 搜索入口使用“寻找下一帧灵感”，推荐入口统一为“为您推荐”。
- 视频标题、简介和 AIGC 字段按 Unicode 字符计数，与数据库字符容量匹配，页面显示“最多多少字”和当前字数。
